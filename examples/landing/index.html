Common questions

How does audit mode score an interface?

Inventory everything visible, score each dimension 0–10 against its rubric question, log findings tagged blocker / major / minor, then normalize to 100 and order fixes by impact divided by effort.

Why are the skills written in English?

Skill files are prompts executed by coding models, and English keeps instruction-following fidelity highest across models. Every trigger phrase doubles as a test case in each skill's EVALS.md prompt suite.

How do I install a skill?

Copy the skill folder into your agent's skills directory — for opencode that is ~/.config/opencode/skills. Each SKILL.md is self-contained with no dependencies, so any agent that reads markdown can use it.
