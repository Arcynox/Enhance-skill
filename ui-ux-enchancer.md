# Affordances & Signifiers — UI/UX Design Skill

## Objetivo

Diseñar interfaces que comuniquen su funcionamiento visualmente, reduciendo la necesidad de instrucciones explícitas.

Una buena interfaz debe permitir que el usuario comprenda rápidamente:

- Qué es interactivo.
- Qué puede hacer.
- Qué está seleccionado.
- Qué está activo.
- Qué está deshabilitado.
- Qué acaba de suceder.
- Qué información es importante.
- Qué elementos están relacionados.
- Qué puede hacer a continuación.

> **La interfaz debe explicar su comportamiento mediante su diseño.**

---

# 1. Affordances

## Definición

Una **affordance** es la capacidad que tiene un elemento para permitir una determinada acción.

| Elemento | Affordance |
|---|---|
| Button | Presionar |
| Input | Escribir |
| Checkbox | Activar / desactivar |
| Switch | Alternar |
| Slider | Desplazar |
| Link | Navegar |
| Card interactiva | Abrir |
| Handle | Arrastrar |
| Select | Seleccionar |
| Tab | Cambiar contenido |

### Principio

> Un elemento interactivo no debería parecer contenido estático.

El usuario debe poder inferir qué puede hacer con un elemento sin necesidad de leer una explicación.

---

# 2. Signifiers

## Definición

Un **signifier** es una señal visual que comunica al usuario cómo funciona un elemento o cuál es su estado.

Ejemplos:

- Hover.
- Focus.
- Active.
- Pressed.
- Selected.
- Disabled.
- Highlight.
- Border.
- Background.
- Underline.
- Icon.
- Cursor.
- Tooltip.
- Chevron.
- Loading indicator.
- Cambio de color.
- Cambio de peso tipográfico.
